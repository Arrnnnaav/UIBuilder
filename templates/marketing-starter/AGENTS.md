# Project rules

## Fresh agent/session setup

Before specialist work, read this file, `docs/AGENT_BOOTSTRAP.md`, `docs/STATE.md`,
`docs/BUILD_SPEC.json`, current approvals and stage artifacts. Shared project files are the
source of context across agents and sessions. Run the task-aware preflight from the UIBuilder
harness checkout; install only missing pinned allowlist entries that are useful for the task:

```powershell
node scripts/agent-bootstrap.mjs --task website --project .
node scripts/agent-bootstrap.mjs --task website --project . --install
```

Use `docs/AGENT_BOOTSTRAP.json` for the exact source, version, license and fallback list.
Paid/unknown-license services, keys, MCP servers, and write/deploy tools are not auto-installed.
A skill being installed does not prove a plugin, hook, browser, model or service is connected.
Follow `brain/tools.json` in the harness for task permissions. Record the bootstrap task,
skills/tools checked and used, and unavailable tools with fallbacks under `environment` in
`docs/handoff/<agent>.json`.
This site was generated by UIBuilder. The pipeline rulebook is `D:\PROJECTS\UIBuilder\AGENTS.md`.
Here, `docs/DESIGN.md` is law, SEO data lives only in `content/` (see README "SEO contract"),
and nothing ships until `pnpm check` and `pnpm perf` pass.
