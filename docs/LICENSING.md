# Repository license decision

UIBuilder has no owner-selected repository license yet. Public visibility alone
does not grant general permission to redistribute its original code. Vendored
materials keep their own upstream license terms; see `.claude/skills/SOURCES.md`.

Recommendation for owner review: MIT is suitable if broad reuse, modification and
commercial use are intended. Apache-2.0 is an alternative if an explicit patent
grant matters. The owner must choose before a root LICENSE is created; neither is
selected by this document. Client site assets and content may need separate terms.
