# Prompt snippets: portfolio
- **Hero copy:** "NAME — ROLE building OUTCOME for WHO." Keep it under 12 words, with no buzzwords.
- **Case-study frame:**
  1. Problem (2 sentences)
  2. Role and constraints
  3. Approach (3 beats)
  4. Result (a number)
  5. Images
- **FAQ seeds:**
  - What does NAME do?
  - What stack does NAME use?
  - Is NAME available for freelance or full-time?
  - How do I contact NAME?
